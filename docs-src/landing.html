Features

Real weather, not a weather icon.

The card does not play a fixed animation per weather state. It reads your entities and sensors and builds the sky from them, by day and by night. Each tile below shows its feature in the card at the top.

Examples

Visual editor

Set it up without writing YAML.

Every option has a switch, a slider or a picker, grouped the way you think about the card, with a short help text and a link to the docs.

  • Chips for any entity, attribute or forecast, as text, ring or bar.
  • Presets from Low for old tablets to Ultra for wall displays.
  • Every effect can be switched off on its own.
  • English or German, following your Home Assistant language.

Install

Up and running in three steps.

Requires Home Assistant 2026.11 or newer.

Add the repository

In Home Assistant open Settings › Marketplace › Add from link and enter whyisthisbroken/atmo-weather-card. Pick Dashboard as the type.

Install the card

Open Atmo Weather Card in the Marketplace, select Install, then reload your dashboard.

Add it to a dashboard

Add a card, search for Atmo Weather Card, or paste this:

type: custom:atmo-weather-card
weather_entity: weather.home

No Marketplace? For the manual install you copy the files of a release into www and add one resource entry.

Questions

Good to know.

Does it work with my weather integration?

Yes, with any weather.* entity. Cloud cover, wind, visibility and dew point are used when your integration provides them, and skipped when it does not.

Will it slow down my wall tablet?

Pick the Low preset for older tablets. The card also pauses when it is off screen or the tab is hidden.

Does it work with imperial units?

Yes. Wind, temperature and rain keep the units of your entities, mph and °F included.

Can I use my own picture of my house?

Yes, a day and a night image sit in front of the sky. See Custom house image.

Does the card send data anywhere?

No. It loads nothing from other servers and talks only to your Home Assistant.

Which languages does the editor speak?

English and German, following your Home Assistant language. Everything else shows English.
