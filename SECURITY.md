# Security Policy

## Supported Versions

Security fixes are provided for the current major version only.

| Version | Supported          |
| ------- | ------------------ |
| 6.x     | :white_check_mark: |
| < 6.0   | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, use GitHub Private Vulnerability Reporting via this repository's
**Security** tab and select **Report a vulnerability**.

Security reports are prioritized over feature requests. If a vulnerability is
confirmed, a fix will be released as soon as practical. Public disclosure will
take place after a patch is available.
